# Codex CLI 개발 작업

OpenGem에서 Codex CLI를 이용하려면 앱을 실행하는 사용자 계정에 CLI 설치와 인증이 필요합니다. Codex CLI는 OpenGem에 내장되어 있지 않습니다.

## 설치 및 인증

[OpenAI Codex 설치 안내](https://github.com/openai/codex#quickstart)에 따라 설치합니다. Node.js를 사용하는 경우 다음 방법도 있습니다.

```bash
npm install -g @openai/codex
codex --version
codex login
codex login status
```

`codex login`에서 ChatGPT 로그인을 마친 뒤 OpenGem을 다시 실행하세요. 터미널에서 명령을 찾을 수 없다면 설치 경로가 PATH에 포함되어 있는지 확인하세요. 앱이 터미널과 다른 환경에서 실행되면 해당 앱에도 같은 PATH가 전달되어야 합니다. API 키 인증 등 자세한 내용은 [공식 인증 문서](https://developers.openai.com/codex/auth)를 참고하세요.

Codex CLI와 OpenGem의 다른 모델 연결 설정은 별개입니다. Codex CLI는 자체 인증 정보를 사용하며 계정의 이용 조건과 사용량이 적용됩니다. `~/.codex/auth.json`이나 API 키가 있다면 비밀번호처럼 보호하고 저장소, 메시지, 로그에 넣지 마세요.

## 에이전트 작업

1. 대화 화면에서 작업할 에이전트를 선택합니다.
2. 프로젝트 메뉴에서 폴더를 연결하고, 실행 방식을 **Codex 개발 실행**으로 선택합니다.
3. 작업 요청을 보내고 진행 상황과 결과를 확인합니다. 실행 중에는 **작업 취소**를 선택할 수 있습니다.

대화 세션의 활성 에이전트와 연결된 첫 번째 프로젝트 폴더가 작업에 사용됩니다. Codex CLI가 실행될 때 최근 대화의 텍스트 최대 20개가 작업 맥락으로 함께 전달됩니다. 이전 CLI 도구 이력은 이어지지 않습니다. 키나 토큰처럼 공유하면 안 되는 정보는 대화에 입력하지 마세요. 에이전트에 설정된 모델 이름이 Codex CLI에 전달됩니다. 다른 공급자의 모델은 CLI에서 지원되지 않을 수 있으므로, 해당 CLI와 인증 계정에서 사용할 수 있는 모델을 에이전트에 지정하세요. 도구, MCP와 인증은 CLI의 설정을 따르며 OpenGem에서 표시하는 연결 설정과 다를 수 있습니다.

동일하거나 서로 상위·하위 관계인 폴더에서 다른 Codex 작업이 실행 중이면 새 작업을 시작할 수 없습니다. 다른 작업이 끝난 뒤 다시 요청하세요. 이 제한은 OpenGem에서 시작한 작업에 적용되며, 외부 프로그램에서 같은 폴더를 변경하는 경우까지 막지는 못합니다.

## 작업 공간과 권한

Codex는 `workspace-write` 샌드박스 정책으로 실행됩니다. 신뢰할 수 있는 프로젝트 폴더만 연결하고, 요청하기 전에 기존 변경 사항을 확인하세요. 에이전트가 파일을 수정하거나 명령을 실행할 수 있으므로 작업 결과와 실행한 검증을 직접 확인해야 합니다. Codex의 샌드박스는 OS와 설치 환경에 따라 제약이 다릅니다. 샌드박스는 모든 데이터나 자격 증명을 보호하는 완전한 격리 환경이 아니며, 프로젝트의 스크립트 및 의존성 실행에도 주의가 필요합니다. Windows 환경 설정과 한계는 [공식 Windows 샌드박스 문서](https://developers.openai.com/codex/windows)를 참고하세요.

여러 에이전트가 같은 폴더에서 동시에 파일을 바꾸면 변경이 충돌하거나 서로의 결과를 덮을 수 있습니다. 독립적인 작업이 필요하면 별도 Git worktree와 브랜치를 사용하고 통합 후 다시 검증하세요. Worktree는 소스 파일을 분리할 뿐 포트, 실행 중인 서비스, 환경 변수, 데이터베이스나 인증 정보를 자동으로 분리하지 않습니다.

## 확인 방법

1. 테스트용 저장소에서 간단한 파일 수정 작업을 요청하고 실제 변경과 응답을 비교합니다.
2. 실행한 테스트 결과를 확인하고 실패 또는 실행할 수 없는 테스트는 따로 기록합니다.
3. 변경 사항은 `git diff`와 테스트 결과를 검토한 후 반영합니다. CLI가 실행되지 않으면 `codex --version`과 `codex login status`를 앱과 같은 사용자 환경에서 확인합니다.

Codex의 명령과 샌드박스 정책은 버전에 따라 변경될 수 있습니다. 현재 동작과 옵션은 [비대화형 실행 문서](https://developers.openai.com/codex/noninteractive)와 설치된 CLI의 도움말을 확인하세요.
